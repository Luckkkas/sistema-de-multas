# 🚗 Sistema de Multas

Projeto de um sistema que verifica a velocidade de um veículo e informa se houve multa.

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript

## 📚 O que pratiquei

- Variáveis
- `if` e `else`
- Operadores de comparação
- Funções
- Eventos
- Manipulação do DOM
- Entrada de dados
- Condicionais em JavaScript

## 🚀 Como executar

Abra o arquivo `index.html` no navegador.
